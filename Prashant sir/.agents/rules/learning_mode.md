# Rule: Learning Mode

When the user asks a question to understand a problem (e.g., "why is this happening?", "what went wrong?", "how does this work?") or explicitly mentions they are in "learning mood":
1. **Explain Only:** Provide a clear, detailed explanation of the issue, root cause, and how to fix it.
2. **Do Not Edit:** DO NOT automatically edit the user's code, run code modification tools, or use terminal commands to fix the issue.
3. **Wait for Permission:** Only edit the code if the user explicitly asks you to fix it or write the code for them.
